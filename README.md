# Earth to Moon Learning Game

Flutter Android game:
- Arabic / English
- Local / offline
- 20 difficulty levels
- Earth-to-Moon space journey
- Stage 1 — rocket journey (lib/rocket_journey.dart): fly a rocket 384,400 km from
  Earth to the Moon, shoot monsters with a pistol, beat the giant Moon monster and land.
  Real milestones are shown on the way: clouds, ozone layer, Kármán line, ISS,
  Van Allen belts, GPS & geostationary satellites, planets, a comet, the Moon's gravity zone,
  with a physics-based speed readout and real mission time.
- Educational questions
- Monsters with increasing level size

GitHub Actions builds the release APK automatically after pushing to main/master.
